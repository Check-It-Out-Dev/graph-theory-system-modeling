## 1 Modal tier — `modal/serve.py`
`modal.App("codemap-big-tier")`; image `modal.Image.from_registry("ghcr.io/ggml-org/llama.cpp:server-cuda", add_python="3.12")`; `modal.Volume("codemap-models")` at `/models`; `@app.function(gpu="A100-80GB", min_containers=0, scaledown_window=300, timeout=3600)` + `@modal.web_server(8000, startup_timeout=600, requires_proxy_auth=True)` spawning `/app/llama-server -m /models/$GGUF -c 12288 -ngl 999 --parallel 2 --cache-prompt --host 0.0.0.0`. Env `CODEMAP_MODAL_GGUF` = 80B IQ4_XS default; `--profile 30b` = L40S. Cold start budget ≤ 180 s (42 GB volume read + CUDA load), smoke asserts < 360 s.
Commands: `modal volume create codemap-models && modal volume put codemap-models bin/models/<gguf> /` (once); `modal deploy applications/CodeMap/modal/serve.py`; `python applications/CodeMap/modal/smoke.py` (GET /health, one `enter(11)` chat, prints cold seconds).
Server side: `CODEMAP_MODAL_URL=https://ramzesx--codemap-big-tier-serve.modal.run`, headers `Modal-Key/Modal-Secret` from `CODEMAP_MODAL_KEY/SECRET` (proxy-auth token, dashboard). Spend guard: Modal workspace limit $60/mo + server credits cap + 300 s scaledown.

## 2 Personas — `eval/humans/`
`personas.json`: 6 rows `{id, model, role_file, slice, questions_per_night, credits_per_night, rubric}` — opus-architect, opus-skeptic (claude-opus-5), sonnet-tester, sonnet-ops (claude-sonnet-5), haiku-newbie, haiku-pm (claude-haiku-4-5) over 104 bank + new `eval/q/probes_offdist.jsonl` (30 off-distribution probes), sliced by kind.
`mcp_bridge.py`: stdlib stdio JSON-RPC MCP (`initialize/tools/list/tools/call`), tools `ask(q,tier?)`→`POST /ask`, `feedback(request_id,rating,rationale)`→`POST /feedback`, header `X-CodeMap-User`. Keeps the stdlib law.
`run_night.py --date D [--dry-run --max-credits 2500]`: per persona `claude -p "<task>" --model M --append-system-prompt-file roles/R.md --mcp-config eval/humans/mcp.json --strict-mcp-config --allowedTools mcp__codemap__ask,mcp__codemap__feedback --max-turns 40 --output-format json`; env `CODEMAP_USER=persona:<id>`, `CLAUDE_CODE_ENABLE_TELEMETRY=1 OTEL_METRICS_EXPORTER=otlp OTEL_LOGS_EXPORTER=otlp OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf OTEL_EXPORTER_OTLP_ENDPOINT=<grafana otlp gateway> OTEL_EXPORTER_OTLP_HEADERS=Authorization=Basic… OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE=cumulative OTEL_METRICS_INCLUDE_ACCOUNT_UUID=false OTEL_RESOURCE_ATTRIBUTES=persona=<id>,night=D`. Joins CLI JSON (cost, usage) with `events.jsonl` rows by user → `eval/humans/runs/D.jsonl` (request_id, persona, model, qid, tier, rating, rationale, tokens, credits, latency_ms, cost_usd). Bridge returns `budget_refusal` at cap.
Gemini path `synthetic.py`: `google-genai` on **Vertex ADC** (`GOOGLE_GENAI_USE_VERTEXAI=true GOOGLE_CLOUD_PROJECT=<gcp-project> GOOGLE_CLOUD_LOCATION=global`), `gemini-2.5-flash-lite`. Why Vertex: ADC and billing already exist, no new long-lived key to store or rotate, same $0.10/$0.40; AI Studio's only edge is a free tier. 3 synthetic personas paraphrase + ask + rate over HTTP, `user=synthetic:<id>`, cap 150/night.

## 3 Judge — `eval/judge/`
`rubric.md`: grounded / correct / abstained-appropriately / helpful, 1–5 anchored; reference = `gold_answer` when qid ∈ bank. `judge.py --mode pointwise --in <run> --out runs/D.json` for traffic; `--mode pairwise --a --b` both orders, disagreement → tie. Gemini flash-lite, temp 0, JSON schema. Rows: `{id, request_id, terminal, gold_fp_hit, content_f1, judge{grounded,correct,abstain,helpful,rationale}, prompt_version, pack_version, model, tier}` + BENCH-shaped `summary` so `harness` re-derives it. Family law: Gemini judges Qwen and Claude; Claude never judges Claude.
`calibrate.py`: κ_oracle = Cohen's κ (judge.correct≥4 vs oracle success) on bank rows; κ_owner = quadratic-weighted κ vs the 30 owner ratings (`/feedback` events, `user=owner`). Gate both ≥ 0.6, else run flagged `uncalibrated` and unusable for claims. Drift: `anchors.jsonl` (20 frozen answers + scores) re-scored each run; mean |Δ| > 0.3 or κ_anchor drop > 0.1 → exit 3 + Grafana annotation.

## 4 Quality rates — `eval/quality/quality.py`
Inputs `telemetry/events.jsonl` + judge + humans runs → `eval/quality/runs/D.json`. Metric names (artifact keys = Prom names): `codemap_grounded_rate` (judge.grounded≥4 ∧ solid), `codemap_abstention_rate{kind=honest|false}`, `codemap_version_drift_rate` (bank qid whose exec-fp/terminal changed across consecutive `(prompt_version,pack_version,model)`), `codemap_rating_mean`, `codemap_rating_ge4_rate`, `codemap_requests_total{tier,model,user_kind,terminal}`, `codemap_tokens_total{tier,model,type}`, `codemap_cache_hit_ratio`, `codemap_credits_total{user}`, `codemap_budget_burn_ratio`, `codemap_latency_ms_p95{tier}`, `codemap_judge_kappa{ref}`.
Committed: `eval/{humans,judge,quality,optimize}/runs/*`, `telemetry/fixtures/events.sample.jsonl` (200 scrubbed rows), `eval/judge/anchors.jsonl`. Gitignored: `telemetry/events.jsonl`, `.env`, `bin/`. Claims: `{"doc":"Readme.md","text":"grounded 0.87","run":"quality/2026-09-20","metric":"codemap_grounded_rate","value":0.87}`.

## 5 GEPA — `eval/optimize/`
Own `pyproject.toml` (`gepa`, `google-genai`, `pytest`). `python -m run --component big_prompt|api_prompt|master_v2 --max-metric-calls 300 --endpoint $CODEMAP_MODAL_URL` (standalone `gepa` has no `auto=`; that is DSPy's — 300 ≈ light). `CodeMapAdapter.evaluate` runs `run_big_loop(strict=True, system=candidate)` (4B v2: `loop_runner.run_loop` on :7348); score = 1.0 oracle success + 0.5·content_f1; `make_reflective_dataset` = digests + oracle verdict + judge rationale (`ScoreWithFeedback`). `constraints.check()` BEFORE scoring: `big_tier_verbs_from_text == core−{cache}∪{cypher}` / `prompt_verb_table == VERBS`; violators score 0 with "verb contract broken". Trainset 60 bank + deduped failure traces (stall/invalid/false-pass); valset 44; promotion measured only on the full frozen 104 via `bench_bigtier.py --system-file`. `promote.py`: `rate.answerable` ↑ ∧ `rate.pass_on_unanswerable` ≥ incumbent ∧ pairwise-swap win ≥ 0.55 with swap-consistency ≥ 0.8 → `gh pr create` (prompt file + BENCH + claims rows); human merges. Never in CI.

## 6 Grafana Cloud — `observability/grafana/`
Push path: **stdlib Influx line-protocol push** (`app/telemetry_push.py` → `…/api/v1/push/influx/write`, Basic `instanceId:GRAFANA_CLOUD_ALLOY_TOKEN`, every 15 s + shutdown; `quality.py --push` nightly). Why: no install on a Windows dev box, stdlib law kept, works for an intermittent process and batch runs, counters arrive as running totals so `max_over_time(x[$__range])` is exactly the public-dashboard law; `/metrics` stays for Alloy on a VPS; Loki rejected (events belong in committed artifacts, second secret).
Dashboards `ai-system.json, happiness.json, usage-tokens.json, credit-rate-card.json` (text panel, markdown table, credits per 1k tokens/tier/cypher step, no currency), `quality-over-time.json, budget-burn.json`: uid `codemap-<name>`, `templating.list: []`, explicit ids, `${DS_PROMETHEUS}`, `$__range` on stats.
`tools/grafana/provision.py --upsert --public [--annotate "prompt promoted …"]`: `POST /api/dashboards/db`, create-or-keep public tokens, write `public-urls.md`, `POST /api/annotations` tags `codemap,promotion`, verify each panel via `POST /api/public/dashboards/<token>/panels/<id>/query`. `tools/grafana/lint.py`: JSON valid, no templating, unique ids, `$__range|rate(` on every stat target, `__inputs` present.

## 7 CI/CD
`ci.yml` + 3 jobs (python 3.12, `pytest==9.1.1 hypothesis==6.135.*`): `telemetry-gate` = `pytest applications/CodeMap/{telemetry,eval/humans,eval/judge,eval/quality}/tests` — replays `events.sample.jsonl`, asserts `eval/quality/fixtures/expected.json`; properties: credits ≥ 0 monotone, tier tokens sum to total, cache ratio ∈ [0,1], totals permutation-invariant, replay idempotent. `governance-docs` = `tools/ci/check_governance.py` (required H2s per card, relative links resolve, Art. 50 line in `app/ui.html`, NIST table has 4 functions). `dashboards-lint` = `tools/grafana/lint.py`. `report.needs` gains all three.
`nightly.yml`: `cron "0 4 * * *"` + dispatch; checkout gh-pages → `quality.py --replay --out site/quality` + `calibrate.py --replay` → peaceiris (same pin). No model, no secrets, `contents: write` only.
`modal-deploy.yml`: dispatch-only, `environment: modal` (required reviewer = owner; `MODAL_TOKEN_ID/SECRET` as environment secrets, not repo), `concurrency: modal-deploy`, pinned `modal`. Verdict: acceptable on a public repo under those two conditions (fork PRs cannot read environment secrets; dispatch needs write + approval; Modal spend limit is the backstop). Local `modal deploy` stays primary.
Six breakages: (1) credits constant ×2 → telemetry-gate; (2) drop `## Intended use` from MODEL_CARD → governance-docs; (3) add a templating var → dashboards-lint; (4) duplicate panel id → dashboards-lint; (5) edit `grounded 0.87` in README → `test_the_document_still_says_it`; (6) flip one `terminal` in the fixture → grounded-rate mismatch + terminal-sum property.

## Revision after the lead's extra facts (same day)

**§1 Modal tier — base on `training/modal_{eval,gguf,train}.py`, not on the embeddings app.** One app `codemap-serve`, one volume `modal.Volume.from_name("codemap-train")` (exists; already holds the trained 4B at `/out/lora-r22-qwen3-4b/gguf/codemap-lora-r22-qwen3-4b-q4_k_m.gguf`). Upload the big GGUF beside it once: `modal volume put codemap-train bin/models/Qwen3-Next-80B-A3B-Instruct-IQ4_XS.gguf /big/`. Image pinned to the same llama.cpp build the box runs: `modal.Image.from_registry("ghcr.io/ggml-org/llama.cpp:server-cuda-b10155", add_python="3.12")` (grammar/decoding semantics identical to `bin/llama/b10155`). Two web servers in the app: `serve_big` (A100-80GB, `/out/big/…IQ4_XS.gguf`, `-c 12288`) and `serve_4b` (L4 $0.80/h, the trained GGUF, `-c 4096`) — the 4B one is what makes the `master_v2` GEPA line and the "box off" iteration cheap. Both `min_containers=0, scaledown_window=300, requires_proxy_auth=True`; no Modal secret needed (only `huggingface` exists and this app does not use it). `modal/iterate.py` = `modal run` wrapper (CPU container, `.remote()` like `modal_eval.py`) that runs `bench_bigtier.py --system-file` / the GEPA loop against the served endpoint so the box need not stay on. Server env: `CODEMAP_MODAL_URL_BIG`, `CODEMAP_MODAL_URL_4B`, `CODEMAP_MODAL_KEY/SECRET`.

**§6 Grafana push — concrete endpoints (eu-west-2).** Influx line-protocol push: `https://influx-prod-24-prod-eu-west-2.grafana.net/api/v1/push/influx/write`, Basic `2644077:<ALLOY token, metrics:write>` (host derived from `prometheus-prod-24`; confirm on the stack's Influx connection page — the write path itself needs no protobuf/snappy, which is why it beats `/api/prom/push` for a stdlib client). Claude Code OTLP: `https://otlp-gateway-prod-eu-west-2.grafana.net/otlp`, Basic `<STACK id>:<token with metrics:write+logs:write>` — stack id ≠ 2644077, read it from the stack's OpenTelemetry page before slice 2; if the ALLOY token lacks `logs:write`, mint `codemap-otlp` as a Cloud Access Policy token. Public dashboards go through the confirmed SA-token path (`POST /api/dashboards/uid/<uid>/public-dashboards`), `provision.py` follows it exactly.

**§7 modal-deploy.yml — the repo holds no secrets today, keep it that way.** Verdict revised: v1 is local-only (`modal deploy` from the box, runbook in `modal/README.md`). Slice 8 ships the dispatch-only workflow with `environment: modal` but the environment (secrets + required reviewer) is created only if the owner wants the reproducibility proof; until then a dispatch fails fast on the missing environment. `nightly.yml` needs no secret at all.

**§2/§3 Gemini auth — zero-key, least-privilege.** No ADC and no key exist; do not download an SA key (long-lived, leakable, and `iam.disableServiceAccountKeyCreation` is the Google-recommended default). Instead: `gcloud iam service-accounts create codemap-judge` → grant it `roles/aiplatform.user` → grant the owner `roles/iam.serviceAccountTokenCreator` on it → `gcloud auth application-default login --impersonate-service-account codemap-judge@<gcp-project>.iam.gserviceaccount.com`. Runtime gets short-lived SA tokens through the owner's refresh token, no key file exists anywhere, the API identity is the least-privileged SA. `google-genai` picks it up with `GOOGLE_GENAI_USE_VERTEXAI=true GOOGLE_CLOUD_PROJECT=<gcp-project> GOOGLE_CLOUD_LOCATION=global`. Cost/pricing unchanged ($0.10/$0.40; Vertex batch −50% available if judge volume grows).
