## 7. Architecture — six planes

1. **Serve plane** (`app/`, stdlib only — `claude_cli.py` shells out to the `claude` binary, no SDK): every `/ask`, `/step`, `/escalate`, `/feedback` and every budget refusal emits ONE sorted JSON line (`schema:1`) into `R/telemetry/events.jsonl` (gitignored artifact of record) through `telemetry.emit()` under a `threading.Lock`; `metrics.Registry` is rebuilt from that file at boot (a view of the artifact) and rendered at `GET /metrics`. One `telemetry.Meter` is threaded through all three loops' `chat()` calls and sums `usage` + `timings`. Users are a declared registry; contexts are in-memory with llama-server slot affinity; credits from a currency-free rate card; daily budgets; `BigNavigator` gains a remote Modal backend; `ids.py` supplies request/prompt/pack/model identity; UI gets a ★ rating widget and the Art. 50 line; `telemetry_push.py` (stdlib) pushes counters to Grafana Cloud.
2. **Persona plane** (`mcp/`, `eval/humans/`): ONE stdlib stdio JSON-RPC MCP server; `app/claude_cli.py` (the one `claude -p` runner, role-tagged telemetry, key unset); 6 Claude Code personas holding multi-turn conversations; the escalation tier's `cli` backend; `run_night.py`.
3. **Judge plane** (`eval/judge/`): Claude Code judge (Sonnet, batched) on Qwen answers; Qwen-80B-on-Modal cross-family check; rubric, pointwise + pairwise-with-swap, κ calibration, anchor drift; Gemini optional.
4. **Quality plane** (`eval/quality/`): folds events + judge + humans into `runs/<date>.json` whose keys are Prom names; gated claims.
5. **Improve plane** (`eval/optimize/`, own pyproject): GEPA adapter with `claude -p` (Sonnet) as the reflection model, contract constraints, promotion gate, PR.

## 13. Laws for this arc (earned before it started — obey, and add your own to Neo4j as they are earned)

- **Two planes.** CI never calls a model, never holds a cloud secret. Everything CI asserts is replayed from a committed artifact.
- **A gate that has never been red is a claim.** Run the six breakages; record which test caught each.
- **Numbers have one home.** A rate in prose = a row in `claims.json` re-derived by `harness.py`; counts (113 → N) are self-asserted — bump README and the assertion in the same commit.
- **`*.json` and `data/` are gitignored repo-wide.** Negate per path; `git check-ignore -v` before trusting `git add`; a green local suite with files CI cannot see is the recorded failure.
- **Backticks in `git commit -m` get command-substituted** — always `git commit -F <file>`.
- **Public commits: real date, no Claude trailer, no `--amend`.** The box clock has jumped a month before; GitHub's timestamps are the authority.
- **Subscription-first.** Every `claude -p` goes through `app/claude_cli.py`, which strips `ANTHROPIC_API_KEY` and tags `role=`; the key-based `api_tier` backend and the Gemini judge are opt-in. A `claude -p` that bills the API is a bug, not a fallback. Verify on the first live call (S0) and the first persona (S8).
- **The subscription window is a shared resource.** Nights run at 03:00, Haiku-first, under credit + turn caps; a rate-limited `is_error` ends the night as `partial: true` — never a crash, never a retry storm. Per-call startup is 3–5 s: batch judge work, never one call per answer.
- **No 80B on this box.** The big tier is Modal; the local box runs the 4B on CPU only.
- **Public dashboards take no template variables**; `max_over_time(x[$__range])`; explicit ids; verify through the public query API.
- **Cumulative temporality** for Claude Code OTLP to Grafana Cloud or counters vanish silently.
- **Judge family ≠ generator family.** Claude (subscription) judges Qwen answers; every Claude-authored answer and a 20 % sample get a second opinion from Qwen-80B on Modal; disputes go to the owner's queue. κ_oracle ≥ 0.6 is a hard gate; a run below it is `uncalibrated` and unusable for claims.
- **The 4B prompt v1 is frozen with the DSL** (`training/FREEZE-v1.md`); optimization targets `big_prompt`, `api_prompt`, and a v2 candidate line — never edits v1.
- **Stdlib in `app/` and `mcp/`.** Dependencies live in `eval/optimize/` and the Modal image only.
- **Cardinality**: `user` only on counters; never `request_id`/`context_id`/`q` as labels.
- **Sonar rules stay ON for `app/server.py`**: loopback URLs and subprocess launches get the existing `# NOSONAR - …; see sonar-project.properties` comment, never a suppressed rule.
- **Main agent writes production code; forks are recon and judging only; ≤ 3 concurrent; judge fork before COMPLETE.**
- **Windows**: `PYTHONUTF8=1 PYTHONIOENCODING=utf-8`; heredocs without `'''`; `ng`-style watcher traps do not apply here, but `test_app.py` needs the pack and the gguf path — run it from `applications/CodeMap`.

Decision log (continues D-lines above):

- **D-R1 (S1).** The remote package is stdlib + `real_ladybug` under `remote/`; handlers are pure `(body, headers) -> (code, obj)`; `mcp.dispatch` is tested without an engine. Streamable HTTP is answered with plain JSON (no SSE): tools only, no server-initiated messages, so the simplest legal shape is the right one. An unknown user is HTTP 400 even on `initialize` — the client fails loudly instead of minting a persona. Pointers rewrite the authoring box's absolute paths into `(repo, relative path)` so the pack can be served from anywhere and no local path leaks.
- **D-R2 (S2).** The navigator tier is one `claude -p` per turn through `app/claude_cli.py` (the only runner; strips the API key, tags `role=`, bare working directory) with `--system-prompt-file prompts/navigator/v1.md` and a loopback stdio MCP (`remote/engine_mcp.py`: `engine_step`, guarded `engine_cypher`, `engine_open`) as its hands; follow-ups `--resume` the Claude session held by the context, so the second turn is a cache read (measured live: 727 cache-creation tokens on turn 2 against 28,968 on turn 1). The prompt is built, not written: `tools/prompt/build_navigator.py` renders the template prose (the object of optimisation) with the L1 index and L2 navigators from the pack (data) and the curation notes (decisions), and `--check` fails when the committed file is stale. Claude Code ignores a `cwd` in an MCP config, so the engine MCP is launched by absolute path. A follow-up inside a conversation never consults the FAQ cache: "and what depends on it?" has no meaning without the context.
- **D-R3 (S3).** Credits are relative units with no currency anywhere (`remote/credits.json`: 1 credit = 10k Sonnet-input-equivalent tokens; Opus 5x, output 5x, cache reads x0.1, cache creation x1.25 — the vendor ratios, not its prices; a live navigator answer costs 20–30 credits). The ledger keys spend on the event UTC date and is rebuilt from `telemetry/events.jsonl` at boot, so a budget survives a restart because it is a fact about the artifact. Budgets are checked before the navigator runs; an exhausted user gets `budget_exhausted` with the seconds to UTC midnight and the engine tools stay free. `GET /metrics` renders a Prometheus view (OTel GenAI semconv histograms plus `codemap_*` counters; `user` only on counters; a forbidden label raises). `telemetry_push.py` sends running totals as Influx lines every 15 s and every event line to Loki with four labels, stdlib only, counted and silent on failure. The 200-row fixture is deterministic (`tools/telemetry/make_fixture.py`, seed 42) and is what CI replays.
- **D-R4 (S4).** Feedback is strict on purpose: it must reference an answer this server gave (a bounded seen-ring rebuilt from ask events), carry exactly one of rating/vote, use the closed tag list, and a rating above 3 requires `verified=true` (the persona opened a pointer) so happiness cannot be rated from the answer text alone. A miss is a file the graph did not know; it lands in `graph/delta/backlog.jsonl`, the saturation backlog the delta pipeline indexes next. `codemap_search` is the only place a non-Claude model runs online: Qwen3-Embedding-8B for recall over a cheap per-entity socket (name, type, package words, subsystem name and responsibilities; the pack ships no embeddings by SCHEMA §4), Qwen3-Reranker-8B for precision on 30 candidates; the index is built once per pack version and cached beside the telemetry; Modal answers a request longer than ~150 s with 303 and a polling URL, which the client follows. A search costs a flat 2 credits plus the query tokens.
- **D-R5 (S5).** The graph pack's home is a GitHub Release (`pack-<semver>`: the tarball, `SHA256SUMS`, release notes with counts and per-file hashes), never a commit: `tools/pack/build_release.py` writes a schema-2 manifest (pack_version, indexed commits per repo, counts, per-file sha256[:16]) and publishes; `tools/pack/fetch_pack.py` verifies the tarball against SHA256SUMS before extracting and refuses tar members that escape the destination. CI, the VPS and a teammate run the same fetch, so the engine check in CI finally runs (it always skipped before, the pack being gitignored) against the same bytes the server serves, and the remote suites run beside it with the model and the network off. `pack-1.0.0` = the 2026-09-03 curated-v2 pack with the v1 workbench CSVs; its indexed commits are unknown until the delta pipeline measures the overlap with the public trees (S11).
- **D-R6 (S6).** The hosted instance is one container on the demo VPS (`python:3.12-slim` + `real-ladybug` + Node 24 + the Claude Code CLI, non-root, 1.2 GB cap, three volumes: pack, telemetry, CLI sessions) behind the host nginx at `codemap.checkitout.app`. The record is DNS-only at Cloudflare because a navigator turn can outlive the proxy's 100 s; the certificate came by HTTP-01 webroot after the DNS-01 hooks hit Cloudflare's 971 throttle from the VPS address (the hooks are unchanged for the other hosts). There is one deploy path, `tools/deploy.sh`, used from a box and by the dispatch-only `deploy-codemap.yml` (environment `codemap-vps` holds only the SSH identity; the application secrets are provisioned by hand in `/opt/codemap/.env`). The active navigator prompt is built at boot and on reload from the template, the pack and the curation notes, and identified by its own sha16, so a new pack moves `prompt_version` too; `POST /admin/reload` and a ten-minute poll of the Releases API swap the pack without a restart.
